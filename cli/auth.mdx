---
title: "CLI authentication"
description: "Sign in with device login, switch workspaces, and manage device sessions."
---

Authenticate `ulysses-cli` with an invited Ulysses account. Sessions are scoped to a workspace (tenant) profile.

## Sign in

```bash
ulysses-cli auth login
```

Optional environment:

```bash
ulysses-cli auth login --env production
ulysses-cli auth login --env staging
ulysses-cli auth login --env local
```

`production` is the default. Complete the browser device-login flow when prompted.

Store the session under a named profile:

```bash
ulysses-cli auth login --profile <name>
```

## Who am I?

```bash
ulysses-cli auth whoami
```

Shows the signed-in principal and active profile.

## Workspaces

List workspaces you can use:

```bash
ulysses-cli auth contexts
```

Activate one:

```bash
ulysses-cli auth use <tenant-id>
```

Select a stored profile for a single invocation with `--profile` (before the subcommand), or set `--config` to override `~/.ulysses/config`.

## Sessions and logout

List device grants:

```bash
ulysses-cli auth sessions
```

Revoke one device grant:

```bash
ulysses-cli auth revoke <session-id>
```

Sign out of the active profile, or every profile:

```bash
ulysses-cli auth logout
ulysses-cli auth logout --all
```

You can also revoke this computer from **Settings → Devices** in the web app.

## Where credentials live

- Tokens: OS keychain when available
- Profile metadata: `~/.ulysses/config` (mode `0600`)
- If the keychain is unavailable, tokens are stored in that config file instead
