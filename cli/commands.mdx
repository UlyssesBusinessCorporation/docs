title: "CLI commands"

---

Invoke the CLI as:

```bash
ulysses-cli [--output json|human] <resource> <action>
```

`--output` must come **before** the subcommand. A terminal defaults to human-readable output; a pipe defaults to JSON. Bare `ulysses-cli` prints the resource tree.

## Authentication

| Command | What it does |
| --- | --- |
| `auth login [--env production\|staging\|local] [--profile <name>]` | Device login; store a tenant profile |
| `auth signup --email <address>` | Email a setup link (finish in the browser, then `auth login`) |
| `auth whoami` | Signed-in principal and active profile |
| `auth contexts` | Workspaces you can use |
| `auth use <tenant-id>` | Activate a tenant profile |
| `auth sessions` | Device grants for the signed-in user |
| `auth revoke <session-id>` | Revoke one device grant |
| `auth logout [--all]` | Revoke the active profile, or every profile |

See [CLI authentication](/cli/auth).

## Portfolio reads

| Command | What it does |
| --- | --- |
| `organizations list [--limit] [--search]` | Organizations in the active tenant |
| `organizations show <organization-id>` | One organization |
| `projects list [--limit] [--offset] [--status] [--search]` | Projects |
| `projects show <project-id>` | One project |
| `matches show <project-id> [--limit]` | Latest stored opportunity matches for a project |
| `opportunities list [--limit] [--offset] [--status] [--listing open\|closed] [--search]` | Funding opportunities |
| `opportunities show <opportunity-id>` | One opportunity |
| `awards list [--limit] [--offset] [--status] [--search]` | Awards |
| `awards show <award-id>` | One award |
| `activity list [--limit]` | Recent activity |
| `links resolve <kind> <id>` | Web URL for a `project`, `opportunity`, or `award` |

Take show IDs from a list result. Do not invent them.

## Portfolio writes

Writes require `project:write` on the active tenant. Only run them when you intend to change data.

| Command | What it does |
| --- | --- |
| `projects create --title --postal-code --project-type [--summary]` | Register a project |
| `projects update <project-id> …` | Update writable fields (summary, identifiers, hold) |

See [Create a project](/guides/create-a-project).

## Meta

| Command | What it does |
| --- | --- |
| `ulysses-cli --version` | Installed version |
| `ulysses-cli update` | Reinstall from [install.tryulysses.com](https://install.tryulysses.com/cli) |

`--config` overrides `~/.ulysses/config`. `--profile` selects a stored profile for one command without changing the active profile.
