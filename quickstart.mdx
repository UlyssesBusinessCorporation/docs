Get from zero to a signed-in session that can read your workspace—reliably and on the path your team will use day to day.

You can start with the **CLI** (recommended for agents and scripts) or the **web app**. Both require an invited account for your organization.

<Note>
  Prefer the app only? Skip to [Use the web app](#use-the-web-app). Prefer the terminal? Follow steps 1–4 below.
</Note>

## Prerequisites

- An invitation or account for your organization
- macOS, Linux, or Windows with a network path to `install.tryulysses.com` and `app.tryulysses.com`
- For the CLI path: `curl` and a shell (the installer brings [uv](https://docs.astral.sh/uv/) if needed)

## 1. Install the CLI

```bash
curl -fsSL https://install.tryulysses.com/cli | sh
```

The script installs uv when missing, downloads the signed wheel from the install host, verifies the SHA-256 and release signature, then installs the `ulysses-cli` command.

Confirm the install:

```bash
ulysses-cli --version
```

Upgrade later with:

```bash
ulysses-cli update
```

Full detail: [CLI](/interfaces/cli).

## 2. Sign in

```bash
ulysses-cli auth login
```

Complete the device login in the browser. Tokens are stored in the OS keychain when available; profile metadata lives in `~/.ulysses/config`.

Check the active principal:

```bash
ulysses-cli auth whoami
```

If you belong to more than one workspace:

```bash
ulysses-cli auth contexts
ulysses-cli auth use <tenant-id>
```

See [CLI](/interfaces/cli).

## 3. List something real

Pick one read that matches your role:

```bash
ulysses-cli organizations list
ulysses-cli projects list
ulysses-cli opportunities list
ulysses-cli awards list
```

Bare `ulysses-cli` prints the command tree. In a terminal you get human-readable output; pipes default to JSON. Force a format with `--output json` or `--output human` before the subcommand.

## 4. (Optional) Use the web app

1. Open [https://app.tryulysses.com](https://app.tryulysses.com) and sign in with your organization’s identity provider.
2. Confirm you are in the correct workspace.
3. Open projects, funding, or chat and complete one concrete task—for example, open a project or ask a question about your portfolio.
